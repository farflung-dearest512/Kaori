## 🔧 Installation Guide

Once you've clicked the download button above, you'll be taken to the Kaori releases page. Here's what to do next:

1. **Find the latest release**: Look for the newest version at the top of the page. It will be labeled with a version number (like "v1.2.0") and a date.
2. **Choose your file**: On the release page, you'll see a list of downloadable files. Look for the file that matches your system. For GNOME users, this is typically a file ending in `.flatpak` or `.tar.gz`. If you're unsure, pick the one labeled "Recommended" or the largest file.
3. **Click to download**: Click on the file name to start the download. Your browser will save it to your Downloads folder.
4. **Open the file**: Once downloaded, double-click the file. Your system will guide you through the installation. For `.flatpak` files, this usually opens the Software Center. For `.tar.gz` files, you may need to extract them and run the included script.
5. **Launch Kaori**: After installation, find Kaori in your applications menu. It might be under "Graphics" or "Office." Click the icon to start reading!

## 🖥️ System Requirements

Kaori is built for GNOME desktop environments on Linux. Here's what you need:

- **Operating System**: A Linux distribution with GNOME 40 or newer (Ubuntu 21.10+, Fedora 34+, etc.)
- **Memory**: At least 2 GB of RAM (4 GB recommended for large comic collections)
- **Storage**: 500 MB of free space for the application, plus space for your comics
- **Display**: A screen resolution of 1280x720 or higher
- **Internet Connection**: Required only for downloading Kaori and updates

## 📂 Supported File Formats

Kaori supports all the most common comic file formats:

- **CBZ** (Comic Book Zip) - The most popular format
- **CBR** (Comic Book RAR)
- **CB7** (Comic Book 7-Zip)
- **PDF** (Portable Document Format)
- **Plain images**: Individual image files (PNG, JPEG, WebP, etc.) in a folder

If you have a format not listed here, check back later—we're always adding new ones!

## ❓ Frequently Asked Questions

**Q: Is Kaori free to use?**
A: Yes, absolutely! Kaori is open-source software, free to download and use for everyone.

**Q: Can I import comics from external drives?**
A: Definitely. Connect your USB drive or external hard disk, and Kaori will scan it when you add the folder to your library.

**Q: How do I update Kaori?**
A: Kaori updates automatically in the background. You can also check for updates manually in the "About" section of the Settings menu.

**Q: Can I read comics offline?**
A: Yes! Once your comics are downloaded to your device, you can read them anywhere without an internet connection.

**Q: My comics are showing in the wrong order. What should I do?**
A: Make sure your files are named with numbers (e.g., "Chapter_01.cbz", "Chapter_02.cbz"). Kaori sorts files alphabetically, so consistent naming helps.

## 🛠️ Troubleshooting

Here are solutions to common issues:

- **Kaori won't launch**: Make sure your system meets the requirements. Try restarting your computer, then launch Kaori from the terminal by typing `kaori` and press Enter. If you see an error, note it down for support.
- **Comics appear blank**: This usually means the file is corrupt or the format isn't supported. Try opening the file in another application to test it.
- **Slow performance**: Close other heavy applications. If the issue persists, try lowering the image quality in Settings.
- **No sound when turning pages**: Sound effects are off by default. Go to Settings > Audio to enable them.

If none of these work, please visit our support page at the GitHub repository and open an issue. We're happy to help!
